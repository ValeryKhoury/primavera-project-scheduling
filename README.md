# Project Scheduling & Cost Estimation with Primavera

Project Management course project, B.E. Industrial Engineering, Lebanese
American University (Jan 2025 – May 2025)

## Overview
A project management exercise using Primavera to plan, schedule, and cost a
project. It covers schedule development, resource allocation, and cost
estimation through a Work Breakdown Structure (WBS).

## What I did
- **Scheduling:** managed project schedules in Primavera, determining the
  overall project duration and the critical activities
- **Resource allocation:** coordinated personnel and materials against project
  needs
- **Cost estimation:** developed and implemented a Work Breakdown Structure
  (WBS) that improved the accuracy of project cost estimates

## Tools used
Primavera 

- `report/`: written report or presentation (PDF)

## Key concepts applied
Critical Path Method (CPM) · Resource allocation · Work Breakdown Structure ·
Cost estimation
